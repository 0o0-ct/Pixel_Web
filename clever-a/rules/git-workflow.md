# Regla de Control de Versiones (Git Workflow)

- **Auto Push obligatorio**: Cada vez que se realicen ediciones, adiciones o modificaciones significativas en el proyecto `Pixel_Web`, se deben realizar los siguientes pasos de Git automáticamente sin necesidad de esperar una instrucción explícita del usuario:
  1. `git add .`
  2. `git commit -m "tipo: descripción clara del cambio"`
  3. `git push origin main`
- **Configuración de Remote**: Asegurarse de que el remote use `git@github.com-agent:0o0-ct/Pixel_Web.git`.
